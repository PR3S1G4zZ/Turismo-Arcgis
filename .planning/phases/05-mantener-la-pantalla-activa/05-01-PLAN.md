<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser Wake Lock API -> React hook | El navegador controla disponibilidad, permiso y liberación del sentinel; el hook acepta esos resultados como no confiables y no deja que una promesa obsoleta altere el ciclo actual. |
| Navegación -> RouteModal | Solo cruza un estado categórico y un mensaje fijo; no cruza excepciones crudas, coordenadas ni geometría. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Denial of Service / resource leak | useWakeLock sentinel and listeners | high | mitigate | Generation guard, one in-flight request, one release listener, cleanup on deactivate/unmount, and tests for late promise and external release. |
| T-05-02 | Availability | useWakeLock integration | high | mitigate | Unsupported/rejected requests update observable state only; no exception escapes and navigation services remain untouched. |
| T-05-03 | Privacy | state/message/tests | medium | mitigate | Expose only availability categories and fixed copy; never pass GPS, heading, route or browser exception details to the UI. |
| T-05-04 | Battery abuse | retry policy | medium | mitigate | Request only during active real navigation and visible document; retry only on visibility return, never periodic polling or hidden media fallback. |
</threat_model>
