# Plan 02-03: integración de flecha y cámara

## Objetivo

Separar la derivación visual del arrow de la condición de seguimiento. MapLibre
seguirá siendo dueño del bearing y `siguiendo` seguirá siendo el único permiso
para ejecutar `easeTo`.

## Tareas (RED → GREEN → REFACTOR)

1. Ampliar el test del mapa para inspeccionar `transform`, simular eventos de
   movimiento/bearing y comprobar que cambiar el rumbo tras un gesto no llama a
   `easeTo`; cubrir también el recentrado y las marcas dev-only.
2. Ejecutar la suite del mapa y confirmar la regresión actual (flecha congelada
   en course-up) o el API faltante.
3. Integrar `bearingViewport`, rumbo de respaldo de la ruta, selector puro y
   rotación relativa; actualizarlo desde `onLoad`/`onMove` y al emitir `easeTo`.
4. Mantener la guarda de cámara `mapListo && enSeguimiento && siguiendo` y
   añadir las marcas de render alrededor de flecha/marcador/cámara.
5. Ejecutar suite afectada, suite completa, lint y build; refactorizar solo con
   pruebas verdes.
